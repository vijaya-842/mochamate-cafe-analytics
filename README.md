# MochaMate — Café Operations Analytics Platform

> Business Analytics Project — Python · SQL · Tableau (2025)

## Overview
A end-to-end data analytics solution for a café business that analyzes sales transactions, menu performance, and customer order data to identify revenue trends and operational inefficiencies — delivered through an interactive Tableau dashboard.

## Key Features
- **Sales & Revenue Analysis** — Identify top-performing menu items and revenue trends over time
- **Menu Performance** — Data-driven insights on item popularity and profitability
- **Operational Insights** — Peak hour analysis for optimized staffing decisions
- **Interactive Tableau Dashboard** — KPI reporting with drill-down capability

## Tech Stack
| Category | Tools |
|---|---|
| Data Processing | Python (Pandas) |
| Database & Querying | SQL |
| Visualization | Tableau |
| Analysis | EDA, Statistical Summarization |

## Dashboard KPIs
- 📈 **Top-Selling Items** — Revenue contribution by menu item
- ⏰ **Peak Hours** — Customer traffic and order volume by time of day
- 💰 **Revenue Breakdown** — Daily, weekly, and monthly revenue trends
- 🍽️ **Menu Optimization** — Underperforming items flagged for review
